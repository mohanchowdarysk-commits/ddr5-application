Fastest scanning (like a store checkout)

  • Aim at the small square code (Data Matrix) on the module label. It holds the part number, serial and size in one read — the long barcode and the tiny codes on the chips are ignored.
  • Best: a 2D handheld barcode scanner (“2D imager”, USB or Bluetooth, about $25–60). It must say 2D / Data Matrix — 1D laser scanners can’t read these labels. Plug it into the PC (or pair it with a phone/tablet in keyboard mode), open the Scan tab and pull the trigger: each read is placed in a tray instantly, no clicks.
  • Phone camera: press 📷 Camera once and keep showing sticks one after another. Hold the phone 15–20 cm away so it can focus; the tray number pops up on the picture. Android phones with Chrome read fastest (built-in reader).

Import & backup

Import reads the original DDR MultiScanner workbook (sheets named like “1-100”, scans in column B) or a file exported from this app, and places every scan in order.

Brand detection rules

Part numbers that start with a prefix win first; then the “contains” list is checked in order (the original workbook's rule). One rule per line: Brand | prefixes | contains, values comma-separated.
